# Comharthai Documentation

This directory contains documentation and visual assets for the Comharthai project.

## Contents

- `screenshots/`: Contains screenshots and visual demonstrations of the application
- Additional documentation files

## Screenshots

The following screenshots demonstrate key features of Comharthai:

1. **API Documentation**: Screenshots of the Swagger UI showing available endpoints
2. **Sign Recognition**: Visual examples of sign language recognition in action
3. **User Interface**: Examples of the user interface for video recording and transcription

## Adding Screenshots

When adding new screenshots:

1. Use descriptive filenames (e.g., `api_endpoints_overview.png`, `isl_recognition_demo.png`)
2. Aim for clear, high-resolution images that demonstrate functionality
3. Update the main README.md to reference new screenshots where appropriate

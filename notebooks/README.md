# Notebooks Directory

This directory contains Jupyter notebooks for experimentation and model training.

## Notebooks

- `ISL_Recognition_Model.ipynb`: Notebook for training the static gesture recognition model
- `Dynamic_Gesture_Recognition.ipynb`: Notebook for training the dynamic gesture recognition model

## Usage with Google Colab

1. Upload these notebooks to Google Colab
2. Mount your Google Drive
3. Upload the ISL-HS dataset to your Google Drive
4. Run the notebooks to train the models
5. Download the trained models and label encoders to the `models` directory

## Requirements

The notebooks require the following libraries:
- OpenCV
- MediaPipe
- TensorFlow
- NumPy
- Matplotlib
- Pandas
- scikit-learn

These are automatically installed in the notebooks.
